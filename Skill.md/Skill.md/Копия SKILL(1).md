# Скилл: Бизнес-аналитик

## Что делает
Берёт файл с данными (Excel, CSV) → проводит глубокий 7-шаговый анализ → выдаёт структурированный отчёт с конкретными рекомендациями.

## Триггеры
- «аналитик»
- «проанализируй данные»
- «что с продажами»
- «найди инсайты»
- «разбери Excel»
- любой загруженный .xlsx / .csv файл + вопрос про анализ

## Вход
- Excel или CSV файл (загруженный в чат или в проект)
- Опционально: контекст бизнеса из CLAUDE.md

## Алгоритм

### Шаг 0 — Загрузка и обзор
Прочитай файл. Определи:
- Сколько листов, строк, колонок
- Какие данные (продажи, расходы, клиенты, товары и т.д.)
- За какой период
- Валюта и единицы

Выведи краткую сводку:
```
📊 Загружено: [название файла]
Листы: [N] | Строк: [N] | Период: [от] — [до]
Данные: [типы данных]
```

### Шаг 1 — АНОМАЛИИ
Найди всё что выбивается из нормы:
- Резкие скачки (>20% от среднего)
- Падения (>15% от предыдущего периода)
- Нетипичные значения (выбросы)
- Нулевые или отрицательные значения там где не должно быть

Формат:
```
🔴 АНОМАЛИЯ: [что] — [значение] vs среднее [значение]
   Возможная причина: [гипотеза]
```

### Шаг 2 — ПАТТЕРНЫ
Что повторяется:
- Сезонность (месяц к месяцу)
- Дни недели (если есть дневные данные)
- Корреляции между показателями (расходы на маркетинг vs выручка)
- Тренды (рост/падение/стагнация)

Формат:
```
📈 ПАТТЕРН: [описание]
   Данные: [цифры]
```

### Шаг 3 — СРАВНЕНИЕ ПЕРИОДОВ
Если данных больше чем за 1 период:
- Текущий vs предыдущий (месяц/квартал)
- Показывай ТОЛЬКО изменения больше 10%
- Считай в абсолютных числах И процентах

Формат таблица:
```
| Показатель | Было | Стало | Δ | Δ% |
```

### Шаг 4 — ГДЕ ТЕРЯЕМ ДЕНЬГИ
- Растущие расходы без роста выручки
- Падающая маржа (если есть данные)
- Самые убыточные позиции/категории
- Неэффективные статьи расходов (ROI < 1)

Формат:
```
💸 ПОТЕРИ: [где] — [сколько теряем] в месяц
   Причина: [почему]
```

### Шаг 5 — ТОЧКИ РОСТА
- Что работает лучше всего (топ-позиции, лучшие дни, каналы)
- Где неиспользованный потенциал
- Куда масштабировать текущий успех

Формат:
```
🚀 РОСТ: [где потенциал] — [оценка в деньгах если возможно]
```

### Шаг 6 — ПРОГНОЗ
На основе текущих трендов:
- Что будет через месяц если ничего не менять
- Оптимистичный сценарий (если применить рекомендации)
- Пессимистичный сценарий (если игнорировать проблемы)

### Шаг 7 — ТОП-3 ДЕЙСТВИЯ
Конкретные действия на ЭТУ НЕДЕЛЮ:
```
✅ ДЕЙСТВИЕ 1: [что сделать]
   Почему: [обоснование из данных]
   Ожидаемый эффект: [цифра]

✅ ДЕЙСТВИЕ 2: ...

✅ ДЕЙСТВИЕ 3: ...
```

## Финальный вывод

Заверши анализ блоком:
```
---
📊 РЕЗЮМЕ
Состояние: [хорошее / требует внимания / тревожное]
Главный инсайт: [1 предложение]
Главный риск: [1 предложение]
Главная возможность: [1 предложение]
---
```

## Правила

1. **Цифры** — каждое утверждение подкреплено конкретным числом из данных. Без «хорошо/плохо» — только цифры.
2. **Бенчмарки** — если знаешь бенчмарки отрасли (из CLAUDE.md или общие), сравнивай с ними.
3. **Не выдумывай** — если данных недостаточно для вывода, скажи прямо: «Для этого вывода нужны данные о [X]».
4. **Язык** — русский, без канцелярита. Как аналитик докладывает директору.
5. **Визуал** — используй эмодзи-маркеры (🔴🟡🟢📈📉💸🚀✅) для быстрого сканирования.
