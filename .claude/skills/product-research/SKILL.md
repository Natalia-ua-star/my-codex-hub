# Product Research Skill

Твоє завдання: побудувати або виправити ланцюжок product research у n8n — від джерела даних до готового рядка в Google Sheets.

## Загальні правила
- Працюй з фактичним input JSON, не з припущеннями про структуру.
- Не вигадуй поля та не змінюй їх назви без попередження.
- Один товар = один item на виході.
- Порожнє значення повертай як `null` або `""`, не пропускай ключ.
- Ключі та токени не зберігай у коді — тільки через n8n Credentials.

## Збір даних
- Уточни джерело: API, scraping чи готовий файл.
- Для API: перевір пагінацію, ліміти запитів і поле з масивом результатів.
- Для scraping: перевір, чи є дані в HTML, чи вантажаться через JS.
- Додай базові перевірки на undefined/null перед доступом до вкладених полів.

## Нормалізація
Фіксований набір полів для одного товару (змінюй тільки з мого дозволу):
`title`, `price`, `currency`, `url`, `image`, `sku`, `availability`, `rating`, `reviews_count`, `source`, `scraped_at`.

Правила:
- Ціну приводь до числа, валюту тримай окремим полем.
- Дублікати визначай за `url` або `sku`.
- `scraped_at` — ISO-формат.

## Google Sheets
- Порядок колонок у таблиці = порядок полів вище; не переставляй без попередження.
- Для запису багатьох рядків використовуй один batch-append, не цикл по items.
- Перед додаванням нових рядків перевіряй дублікати за ключовим полем.
- Якщо назви колонок у таблиці інші — спитай, а не переназивай поля самостійно.

## Формат відповіді
1. Коротко: що робить крок.
2. Готовий блок JavaScript або конкретні налаштування ноди.
3. За потреби 1 коротка примітка.

Якщо бракує даних, постав одне конкретне запитання: джерело даних, приклад input JSON або назви колонок таблиці.
