# Skill: dropshipping-product-research

## Що робить
Знаходить і аналізує потенційні товари для дропшипінгу: оцінює попит, конкуренцію, маржинальність і якість постачальників. Виводить короткий звіт-рейтинг по кожному товару.

## Тригери
- "знайди товар для дропшипінгу"
- "що зараз продається"
- "product research"
- "аналіз товару"
- "порівняй ці товари"
- "які товари в тренді"

## Вхідні дані
- Ніша або категорія (обов'язково)
- Цільова країна продажів
- Бажаний ціновий діапазон продажу ($)
- Бажана мінімальна маржа (за замовчуванням: 40%)

## Алгоритм (кроки)

### Крок 1 — Генерація списку кандидатів
Для заданої ніші запропонуй 5–8 товарів-кандидатів. Критерії відбору:
- Вирішує конкретну проблему або викликає емоцію
- Не продається у великих роздрібних мережах (IKEA, H&M тощо)
- Має потенціал для відео-реклами (демонстрація ефекту)
- Вага до 1 кг (дешевша доставка)

### Крок 2 — Аналіз попиту
Для кожного товару перевір:
- Google Trends: динаміка за 12 місяців (зростання / стабільний / падіння)
- Сезонність: чи є піки попиту?
- Обсяг пошукових запитів (orієнтовно)

### Крок 3 — Аналіз конкуренції
- Кількість оголошень Facebook/Instagram Ads (оцінка через Meta Ad Library)
- Чи є бренди з великим бюджетом? (небезпечно)
- Чи є прості дропшипери без бренду? (добре — є куди вклинитись)
- Наявність на Amazon: рейтинг, кількість відгуків у топ-продавця

### Крок 4 — Розрахунок маржі
Для кожного товару:
```
Ціна постачальника (AliExpress/CJ): $X
Доставка: $Y
Ціна продажу: $Z
Маржа = (Z - X - Y) / Z × 100%
Мін. прийнятна маржа: 40%
```
Додай витрати на рекламу: ~$10–15 на замовлення (Facebook/TikTok Ads).

### Крок 5 — Оцінка постачальника
- Рейтинг продавця AliExpress: мін. 95%
- Кількість замовлень: мін. 500+
- Час обробки замовлення: до 3 днів
- Наявність AliExpress Premium Shipping або ePacket

### Крок 6 — Скоринг та рекомендація
Оціни кожен товар за шкалою 1–5:
| Критерій | Вага |
|---|---|
| Попит (тренд) | 25% |
| Маржа | 30% |
| Конкуренція | 20% |
| Постачальник | 15% |
| Viral-потенціал | 10% |

## Формат виводу
Таблиця з колонками:
- Товар
- Ціна закупки / Ціна продажу / Маржа%
- Тренд (↑↗→↘↓)
- Конкуренція (низька/середня/висока)
- Оцінка (1–5 ⭐)
- Рекомендація (Так / Ні / Протестувати)

Після таблиці — топ-1 рекомендований товар з обґрунтуванням.

## Правила
- Ніколи не рекомендуй товари з маржею < 35% без застереження.
- Товари з порушенням авторських прав (брендові підробки) — не рекомендувати.
- Додай колонку "Search date" з поточною датою у таблицю.
- Якщо DSers доступний — запропонуй одразу знайти постачальника через `dsers-mcp-product`.
