# Skill: shopify-product-preflight

## Що робить

Проводить систематичну перевірку картки товару в Shopify перед публікацією. Знаходить помилки у SEO, тексті, фото, ціні та тегах. Виводить чекліст з оцінкою готовності та списком виправлень.

## Тригери

- "перевір товар перед публікацією"
- "preflight"
- "готовий до публікації?"
- "аудит картки товару"
- "перевір продукт"
- "що не так з товаром"

## Вхідні дані

- ID або назва товару в Shopify (обов'язково)
- Цільова аудиторія / ключові слова (опціонально)
- Конкурент для порівняння (опціонально)

## Алгоритм (кроки)

### Крок 1 — Отримання даних товару
Через Shopify MCP отримай:
- Назва (title), опис (body_html), зображення, ціна, теги, тип, постачальник
- SEO-поля: meta title, meta description, URL handle
- Статус: draft / active / archived

### Крок 2 — Перевірка заголовку
Критерії хорошого title:
- Довжина: 40–70 символів
- Містить головний ключ (що це за товар?)
- Не містить ALL CAPS або зайвих спецсимволів
- Не копіює AliExpress-назву дослівно ("2024 New Arrival Hot Sale...")
- Формат: [Прикметник] + [Назва товару] + [Ключова характеристика]

### Крок 3 — Перевірка опису
Чекліст опису:
- [ ] Є заголовок H2 або H3 всередині опису?
- [ ] Довжина: мін. 150 слів, оптимум 300–500
- [ ] Є bullet points (переваги, характеристики)?
- [ ] Вказані матеріал, розмір, колір, вага (якщо релевантно)?
- [ ] Є заклик до дії (CTA) в кінці?
- [ ] Відсутні граматичні помилки?
- [ ] Текст написаний для покупця, а не для роботів?

### Крок 4 — Перевірка SEO
- **Meta title:** 50–60 символів, містить ключ + бренд
- **Meta description:** 120–155 символів, містить CTA
- **URL handle:** лише латиниця, дефіси, без стоп-слів (the, a, of)
- **Alt text зображень:** описові, містять ключ

### Крок 5 — Перевірка зображень
- [ ] Мінімум 3 фото (краще 5–8)
- [ ] Перше фото: білий фон або lifestyle, чітке, мін. 800×800px
- [ ] Є фото "в дії" / lifestyle?
- [ ] Зображення не містять чужих логотипів або водяних знаків?
- [ ] Розмір файлу: до 1 MB кожне (для швидкості)

### Крок 6 — Перевірка ціни
- [ ] Ціна відповідає формулі: закупка × 2.5–3.5 мін.
- [ ] Встановлено "Compare at price" (закреслена стара ціна)?
- [ ] Ціна закінчується на .99 або .95 (психологія)?
- [ ] Перевірено ціни конкурентів на аналогічний товар?

### Крок 7 — Теги і колекції
- [ ] Товар прив'язаний до мін. 1 колекції?
- [ ] Теги заповнені (5–15 тегів)?
- [ ] Тип продукту (Product Type) вказаний?
- [ ] Vendor / постачальник вказаний?

### Крок 8 — Інвентаризація і доставка
- [ ] SKU вказаний?
- [ ] Вага товару вказана (для розрахунку доставки)?
- [ ] Відстеження запасів: "Don't track" або коректна кількість?

### Крок 9 — Фінальна оцінка
Підрахуй кількість виконаних пунктів. Оцінка готовності:
- 90–100%: ✅ Готово до публікації
- 70–89%: ⚠️ Потребує незначних правок
- < 70%: ❌ Не публікувати — потрібні виправлення

## Формат виводу

```
PREFLIGHT: [Назва товару]
Оцінка: X/100 — [статус]

✅ Виконано: [список]
❌ Проблеми:
  - [проблема] → [конкретне виправлення]

Наступний крок: [дія]
```

## Правила

- Ніколи не схвалюй товар з оцінкою < 70% до публікації.
- Якщо опис схожий на AliExpress-текст — направ в `shopify-product-copywriter`.
- Якщо немає SEO-метаданих — заповни автоматично або запропонуй варіант.
- Перевіряй товар після кожного редагування якщо просять "перепровір".
- Зберігай об'єктивність: хваліть лише те, що дійсно добре зроблено.
