# Skill: shopify-landing-page-builder

## Що робить

Проєктує структуру лендінгу для Shopify під конкретний товар або кампанію: визначає секції, формулює тексти, описує блоки для верстки у редакторі теми або Pagefly/GemPages. Результат — готовий бриф або wireframe для реалізації.

## Тригери

- "зроби лендінг"
- "landing page"
- "сторінка для товару"
- "створи сторінку під рекламу"
- "лендінг під кампанію"
- "посадочна сторінка"

## Вхідні дані

Запитай:
1. Товар або колекція для лендінгу
2. Джерело трафіку (Facebook Ads / TikTok / Google / Email)
3. Ціль сторінки (купівля / збір email / перехід в колекцію)
4. Аудиторія (хто приходить на сторінку?)
5. Доступні інструменти (нативний редактор Shopify / Pagefly / GemPages / Shogun)

## Алгоритм (кроки)

### Крок 1 — Визначення типу лендінгу
- **Product landing page:** для одного товару-героя (найпоширеніше у дропшипінгу)
- **Collection landing page:** для категорії товарів
- **Lead capture page:** збір email за магніт
- **Sale/Campaign page:** обмежена акція з таймером

### Крок 2 — Структура лендінгу (каркас)
Стандартна структура product landing page:

**Секція 1 — HERO**
- Заголовок H1: головна вигода (не назва товару)
- Підзаголовок: уточнення + для кого
- Фото/відео товару (lifestyle, якісне)
- CTA кнопка: "Get Yours Now" / "Order Today"
- Trust bar: (★★★★★ 2 847 reviews | Free Shipping | 30-Day Returns)

**Секція 2 — ПРОБЛЕМА / РІШЕННЯ**
- Блок "Чи знайоме тобі це?" — 3 проблеми аудиторії
- Перехід: "Саме тому ми створили [назву товару]"

**Секція 3 — ПЕРЕВАГИ (Benefits)**
- 3–4 карточки: іконка + заголовок + 1 речення опису
- Акцент на результат, не на матеріал/розмір

**Секція 4 — ДЕМОНСТРАЦІЯ**
- Фото / GIF / відео товару в дії
- "До і після" або порівняння (якщо застосовно)

**Секція 5 — СОЦІАЛЬНИЙ ДОКАЗ**
- Відгуки з фото (мін. 3, краще 6–8)
- Зірки, ім'я, дата, текст відгуку

**Секція 6 — ХАРАКТЕРИСТИКИ**
- Таблиця або список технічних деталей
- FAQ (3–5 найчастіших питань)

**Секція 7 — URGENCY + CTA**
- Таймер зворотного відліку (акція, кількість в наявності)
- Повторення CTA кнопки
- Trust badges: безпечна оплата, гарантія

**Секція 8 — FOOTER**
- Посилання на Shipping / Return Policy
- Контактна інформація

### Крок 3 — Тексти для кожної секції
Для кожної секції напиши:
- Заголовок (H2 або H3)
- Основний текст (2–4 речення максимум)
- Текст CTA-кнопки

Принципи копірайтингу лендінгу:
- Hero-заголовок: "[Число/результат] + [аудиторія] + [вигода]" або питання
- Уникай "We" — пиши "You"
- Кожна секція веде до наступної логічно

### Крок 4 — Мобільна версія (чекліст)
- [ ] Hero-секція видна без скролу на iPhone SE (375px)?
- [ ] CTA кнопка: мін. 48px висота (зручно тиснути)
- [ ] Текст читабельний без зуму (мін. 16px)
- [ ] Відео не автовідтворюється зі звуком
- [ ] Зображення не обрізаються на мобільному
- [ ] Форма оплати зручна на мобільному

### Крок 5 — Налаштування в Shopify
**Нативний редактор теми:**
- Додай нову сторінку: Online Store → Pages → Add page
- Або використай template "page.landing" якщо є
- Секції додавай через Customize → Add Section

**Pagefly / GemPages (рекомендовано для складних лендінгів):**
- Drag-and-drop редактор
- Готові шаблони для product pages
- Вбудована A/B перевірка

### Крок 6 — UTM і аналітика
- URL лендінгу: `/pages/[product-name]-sale` або `/products/[slug]?ref=fb`
- Додай UTM параметри до рекламних посилань
- Підключи Hotjar або Microsoft Clarity для запису сесій
- Ціль у GA4: покупка або add-to-cart

## Правила

- Лендінг завжди має одну мету — не намагайся досягнути всього одразу.
- Якщо трафік з платної реклами — сторінка має відповідати меседжу в оголошенні (message match).
- Не використовуй стокові фото людей — лише реальні фото товару або аудиторія не вірить.
- Таймер urgency повинен бути реальним або постійно скидатись — фейковий таймер шкодить довірі.
- Після публікації — передай в `shopify-conversion-optimization` для аудиту через тиждень.
