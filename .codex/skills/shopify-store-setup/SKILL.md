# Skill: shopify-store-setup

## Що робить

Налаштовує новий Shopify-магазин з нуля до стану "готово до продажів": реєстрація, домен, тема, базові налаштування, юридичні сторінки, платіжні системи і перша колекція. Виводить чекліст прогресу.

## Тригери

- "налаштувати новий Shopify-магазин"
- "store setup"
- "з чого почати Shopify"
- "створити магазин"
- "відкрити Shopify"
- "базові налаштування магазину"

## Вхідні дані

Запитай:
1. Назва магазину (або потрібно придумати — тоді `dropshipping-brand-builder`)
2. Ніша / тип товарів
3. Цільова країна продажів і валюта
4. Чи є акаунт Shopify? (так / ні — тоді допоможи зареєструватись)
5. Бюджет на тему (безкоштовна / платна)

## Алгоритм (кроки)

### Крок 1 — Реєстрація і початкові налаштування
1. Перейди на shopify.com → "Start free trial"
2. Заповни email, пароль, назву магазину
3. Вибери країну реєстрації бізнесу (впливає на Shopify Payments)
4. Ігноруй wizard — одразу переходь до Admin

**Перше що зробити в Admin:**
- Settings → Store details: заповни адресу, часовий пояс, валюту
- Settings → Plan: обери Basic ($29/міс) після тестового периоду

### Крок 2 — Домен
**Варіанти:**
- Купити через Shopify (Settings → Domains → Buy new domain): $14–20/рік
- Підключити зовнішній (Namecheap, GoDaddy, Google Domains): безкоштовно підключення
- Залишити .myshopify.com: тільки для тестування, не для продажів

**Рекомендації щодо домену:**
- Формат: [назвабренду].com
- Уникай дефісів і цифр
- Перевір: чи не схожий на trademark конкурента
- Після підключення: встанови основний домен і редирект з www

### Крок 3 — Тема
**Безкоштовні (достатньо для старту):**
- Dawn — найшвидша, чиста, підходить для більшості ніш
- Sense — краса, догляд, lifestyle
- Craft — handmade, натуральні товари
- Ride — спорт, активний відпочинок

**Платні (якщо бюджет є):**
- Booster ($299 one-time) — конверсійна, багато функцій
- Turbo ($350) — швидка, для великого каталогу

**Встановлення:**
Online Store → Themes → Explore free themes / Visit Theme Store
Після встановлення: Customize — налаштуй лого, кольори, шрифти.

### Крок 4 — Базові налаштування магазину
**Settings → General:**
- [ ] Назва магазину
- [ ] Контактний email (не gmail для довіри: info@[домен].com)
- [ ] Одиниці: метричні або imperial залежно від ринку

**Settings → Checkout:**
- [ ] Customer accounts: Optional (не обов'язкова реєстрація)
- [ ] Форма checkout: ввімкни "Phone number" якщо потрібен
- [ ] Tipping: вимкни якщо не потрібно

**Settings → Notifications:**
- [ ] Email-підтвердження для покупця: перевір і відредагуй шаблон
- [ ] Додай свій брендинг в email-шаблон

### Крок 5 — Платежі
**Settings → Payments:**
- Shopify Payments (якщо доступно в країні) — найнижча комісія
- PayPal — обов'язково додати як резервний варіант
- За потреби: Stripe, Apple Pay (увімкнеться автоматично з Shopify Payments)

**Для України / СНД-ринку:**
- LiqPay, WayForPay, Monobank — через стороннього провайдера

### Крок 6 — Доставка
**Settings → Shipping and delivery:**
- Видали всі стандартні зони і тарифи
- Додай зону "International" (або конкретну країну)
- Тариф: "Free Shipping" (рекомендовано — включи в ціну)
- Або: Flat rate $4.99, Free over $35

**Важливо:** вкажи очікуваний час доставки у Shipping Policy (7–20 днів для AliExpress).

### Крок 7 — Юридичні сторінки
**Settings → Policies → Generate from template:**
- [ ] Privacy Policy (обов'язково для GDPR якщо ринок ЄС)
- [ ] Refund Policy (вкажи реальні умови: 30 днів рекомендовано)
- [ ] Terms of Service
- [ ] Shipping Policy (зроби вручну — вкажи реальні терміни)

Після генерації — відредагуй: вкажи реальну назву магазину, email, умови.

### Крок 8 — Navigation (Меню)
**Online Store → Navigation:**
- Header menu: Home, Collections, About Us, Contact
- Footer menu: Shipping Policy, Refund Policy, Privacy Policy, FAQ

### Крок 9 — Перша колекція
- Products → Collections → Create collection
- Назва, опис, фото обкладинки
- Умова: автоматична (за тегом) або ручна
- Додай в хедер меню

### Крок 10 — Фінальний чекліст перед публікацією
- [ ] Домен підключено і показує магазин
- [ ] Лого та кольори налаштовані
- [ ] Хоча б 1 товар доданий
- [ ] Всі юридичні сторінки є
- [ ] Платіжна система протестована (тестове замовлення через Bogus Gateway)
- [ ] Доставка налаштована
- [ ] Email-повідомлення відредаговані
- [ ] Магазин видимий (Settings → Online Store → пароль вимкнений)

## Правила

- Не публікуй магазин без юридичних сторінок — ризик блокування від Shopify і Meta Ads.
- Тестове замовлення через Bogus Gateway — обов'язкове до першої реклами.
- Якщо назви немає — зупинись і запусти `dropshipping-brand-builder` першим.
- Не рекомендуй платні теми якщо бюджет < $500 — Dawn достатній для початку.
- Після setup — передай в `shopify-dropshipping` для налаштування дропшипінг-додатків.
