# zapier-automation

## Що робить

Проектує та налаштовує Zap-автоматизації в Zapier. Охоплює одно- та багатокрокові Zaps, фільтри, форматери, шляхи (Paths), затримки та webhooks.

## Тригери

- "автоматизація в Zapier"
- "Zap"
- "підключи через Zapier"
- "зроби Zap"
- "Zapier інтеграція"
- "налаштуй тригер Zapier"

## Вхідні дані

- Опис бізнес-процесу: що запускає автоматизацію і що має статись
- Список додатків (Trigger App → Action App)
- Акаунти / підключення, що вже є в Zapier
- Умови фільтрації або гілки логіки (якщо є)

## Алгоритм

1. **Визначити тригер** — знайти правильний Trigger App + Event (New Record, New Email, Webhook тощо).
2. **Спроектувати кроки** — скласти лінійний або розгалужений ланцюг: Trigger → Filter → Action 1 → Action 2.
3. **Налаштувати маппінг полів** — вказати які поля тригера потрапляють у кожну дію.
4. **Додати Filter / Paths** — Filter зупиняє Zap якщо умова хибна; Paths створює гілки (тільки Zapier Professional+).
5. **Formatter** — якщо потрібна трансформація тексту, дати, числа — вставити крок Zapier Formatter.
6. **Delay** — якщо потрібна затримка перед дією — додати крок Delay by Zapier.
7. **Тестування** — запустити Test trigger → перевірити дані → протестувати кожен Action крок.
8. **Увімкнення та моніторинг** — увімкнути Zap, перевірити Task History через 24 год.

## Правила

- Назву Zap робити зрозумілою: `[Trigger App] → [Action App]: [що відбувається]`.
- Для Shopify-тригерів використовувати офіційний Shopify app, не Webhook, де можливо.
- Якщо потрібен двосторонній зв'язок — будувати два окремі Zaps, не один.
- Paths доступні лише на платних планах — перевірити план перед проектуванням.
- Для передачі масивів між кроками використовувати Line Items або Formatter → Split Text.
- Webhooks by Zapier (Catch Hook) — використовувати для кастомних джерел без готового app.
- Не зберігати чутливі дані (паролі, токени) у текстових полях кроків.

## Формат виходу

```
## Схема Zap
Trigger: [App] — [Event]
↓
Filter: [умова] (якщо є)
↓
Step 2: [App] — [Action] | Маппінг: поле_тригера → поле_дії
↓
Step 3: [App] — [Action] | Маппінг: ...

## Налаштування кроків
| Крок | App | Event/Action | Ключові поля |
|------|-----|--------------|-------------|
| 1    | ... | ...          | ...         |

## Обмеження і рекомендації
- [список нюансів]

## Наступні дії
- [ ] Підключити акаунти в Zapier
- [ ] Протестувати тригер
- [ ] Увімкнути Zap
```
