# Навичка: zapier-automation

## Що робить
Проєктує Zap-автоматизації в Zapier: від простих двокрокових до складних multi-step Zaps з фільтрами, форматерами та розгалуженнями (Paths).

## Тригери (коли активується)
- "автоматизація в Zapier"
- "зроби Zap"
- "підключи через Zapier"
- "Zapier інтеграція"
- "налаштуй Zapier"

## Вхідні дані (що запитати у користувача)
1. **Мета** — що повинен робити Zap? (напр. "Gmail → Google Sheets")
2. **Trigger App** — яка подія запускає Zap?
3. **Action App(s)** — які дії виконати (одна чи кілька)?
4. **Фільтри** — чи потрібно фільтрувати дані (напр. "тільки якщо сума > 100")?
5. **Акаунти** — які додатки вже підключені в Zapier?
6. **Тарифний план** — Free / Starter / Professional (впливає на доступні кроки)

## Алгоритм (кроки)

### Крок 1 — Визначення структури Zap
- Trigger: App + Event (напр. Shopify → New Order)
- Actions: послідовний список (App + Action для кожного кроку)
- Виявити необхідність Filters, Paths, Formatter, Delay

### Крок 2 — Mapping даних
- Визначити які поля з тригера потрібні в кожній дії
- Описати трансформації (Formatter: Text, Numbers, Dates)
- Вказати fallback-значення для необов'язкових полів

### Крок 3 — Логіка розгалужень (якщо потрібно)
- Paths: визначити умови кожного шляху (Path A / Path B)
- Filters: вказати точні умови (поле + оператор + значення)
- Loops (тільки Professional+): описати ітерацію по масиву

### Крок 4 — Покрокова інструкція налаштування
```
1. Zapier → Create Zap
2. Trigger: вибрати [App] → [Event]
   - Підключити акаунт → авторизація OAuth
   - Налаштувати поля тригера
   - Протестувати тригер (знайти тестові дані)
3. [Filter/Path — якщо потрібно]
4. Action 1: вибрати [App] → [Action]
   - Mapping полів: [Trigger Field] → [Action Field]
   - Тест дії
5. Повторити для Action 2..N
6. Назвати Zap → Увімкнути
```

### Крок 5 — Перевірка та оптимізація
- Перевірити ліміт кроків для тарифного плану
- Оцінити кількість Tasks на місяць
- Запропонувати альтернативу якщо Zapier дорогий (Make.com)

## Формат виводу
```
## Zap: [Назва]

### Структура
Trigger: [App] → [Event]
Step 2: [Filter/Path — опціонально]
Step 3: [App] → [Action]
Step N: [App] → [Action]

### Mapping полів
| Тригер | → | Дія |
|--------|---|-----|
| ...    |   | ... |

### Покрокова інструкція
1. ...

### Ліміти та оцінка Tasks
- Очікувано Tasks/місяць: ~X
- Мінімальний план: [Free/Starter/Professional]
```

## Правила
- Завжди перевіряти сумісність кроків з тарифним планом
- Для складної логіки (Paths, Loops) — рекомендувати Professional план або Make.com
- Нагадати про тестування кожного кроку перед увімкненням
- Якщо потрібен webhook — пояснити різницю Catch Hook vs Instant trigger
- Для Shopify + Zapier — уточнити тип події (New Order vs Updated Order)
