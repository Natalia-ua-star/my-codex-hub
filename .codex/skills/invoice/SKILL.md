# Скилл: Генератор счетов

## Что делает
Берёт короткую команду → генерирует профессиональный PDF-счёт с реквизитами, QR-кодом, логотипом и стильным дизайном.

## Триггеры
- «счёт [клиент] [сумма] [услуга]»
- «выстави счёт»
- «invoice»
- «создай счёт для...»

## Вход
Команда в свободной форме, например:
- «счёт Старт Медиа 28500 поставка кофе»
- «выстави счёт для ООО Рога и Копыта, 150000 руб, консультация по маркетингу»

## Где брать реквизиты
1. Сначала ищи файл с реквизитами в проекте: `реквизиты*.md`, `invoice*.md`, `requisites*.md`
2. Если нет — ищи в CLAUDE.md секцию с реквизитами
3. Если нигде нет — спроси пользователя

## Алгоритм

### Шаг 1 — Распарсить команду
Из команды пользователя извлечь:
- Название клиента (покупатель)
- Сумма
- Описание услуги/товара
- ИНН клиента (если указан)

### Шаг 2 — Загрузить реквизиты
Найти файл с реквизитами в проекте. Извлечь:
- Название продавца (ИП/ООО)
- ИНН, КПП, ОГРНИП
- Расчётный счёт, банк, БИК, К/с

### Шаг 3 — Сгенерировать номер счёта
Формат: С-[ГГММ]-[001]
Пример: С-2604-001 (апрель 2026, первый счёт)

### Шаг 4 — Создать PDF

Используй Python (reportlab) для генерации PDF.

**Структура счёта:**

```
┌─────────────────────────────────────┐
│  [ЛОГОТИП]     СЧЁТ НА ОПЛАТУ      │
│               № С-2604-001          │
│               от [дата]             │
├─────────────────────────────────────┤
│  ПРОДАВЕЦ           ПОКУПАТЕЛЬ      │
│  ИП Соколов А.И.    ООО «Клиент»   │
│  ИНН: ХХХХ          ИНН: ХХХХ      │
│  Р/с: ХХХХ          КПП: ХХХХ      │
│  Банк: ХХХХ                        │
├─────────────────────────────────────┤
│  № │ Наименование    │ Кол │ Сумма │
│  1 │ [услуга/товар]  │  1  │ XXXXX │
├─────────────────────────────────────┤
│               ИТОГО: XX XXX руб.    │
│               НДС: не облагается    │
│               (или 20% — XX XXX р.) │
├─────────────────────────────────────┤
│  [QR-КОД]    Счёт действителен     │
│              5 рабочих дней         │
│                                     │
│  Подпись: ________________          │
└─────────────────────────────────────┘
```

**Дизайн:**
- Акцентный цвет: тёмно-синий (#1F3864) для заголовков
- Фон шапки: светло-серый (#F5F5F5)
- Шрифт: чистый, без засечек
- QR-код: генерируй через qrcode library (pip install qrcode)
- Содержимое QR: `ST00012|Name=[Продавец]|PersonalAcc=[Р/с]|BankName=[Банк]|BIC=[БИК]|CorrespAcc=[К/с]|Sum=[сумма в копейках]|Purpose=Оплата по счёту [номер]`

**Python-зависимости:**
```bash
pip install reportlab qrcode pillow --break-system-packages
```

**КРИТИЧНО — Кириллический шрифт:**
Стандартные шрифты reportlab (Helvetica, Times) НЕ поддерживают кириллицу — будут квадратики.
ОБЯЗАТЕЛЬНО зарегистрируй DejaVu Sans перед генерацией:
```python
from reportlab.pdfbase import pdfmetrics
from reportlab.pdfbase.ttfonts import TTFont

pdfmetrics.registerFont(TTFont('DejaVu', '/usr/share/fonts/truetype/dejavu/DejaVuSans.ttf'))
pdfmetrics.registerFont(TTFont('DejaVuBold', '/usr/share/fonts/truetype/dejavu/DejaVuSans-Bold.ttf'))
```
Используй 'DejaVu' и 'DejaVuBold' вместо 'Helvetica' ВЕЗДЕ в документе.

**Ключевые правила генерации:**
- Все суммы: формат с пробелами (28 500 руб.)
- Сумма прописью: «Двадцать восемь тысяч пятьсот рублей 00 копеек»
- Дата: формат «03 апреля 2026 г.»
- Если ИП на УСН: «Без НДС (УСН)»
- Если ООО на ОСНО: «В т.ч. НДС 20%: [сумма]»

### Шаг 5 — Сохранить и показать

Сохрани PDF в папку проекта:
```
счёт-[клиент]-[дата].pdf
```

Покажи пользователю ссылку на файл.

Выведи:
```
✅ Счёт создан!
📄 Файл: счёт-[клиент]-[дата].pdf
💰 Сумма: [XX XXX] руб.
🏢 Клиент: [название]
📱 QR-код для оплаты: внутри PDF
```

## Пакетный режим

Если пользователь даёт список клиентов:
```
Счета:
1. Старт Медиа — 28500 — поставка кофе
2. АйТи Солюшнс — 45000 — консультация
3. Дизайн Бюро — 12000 — кофе для офиса
```

→ Создай все счета одним циклом, сохрани каждый отдельным PDF.

## Правила

1. **Реквизиты из проекта** — никогда не выдумывай ИНН, расчётные счета. Бери только из файлов.
2. **QR обязателен** — если библиотека qrcode недоступна, предупреди и создай счёт без QR.
3. **Сумма прописью** — всегда добавляй.
4. **Язык** — русский. Формат документа — российский стандарт.
