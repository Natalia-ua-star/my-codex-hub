# apify-spy-research

## Що робить

Проводить конкурентний аналіз та збір даних з відкритих джерел за допомогою Apify-акторів: парсинг Shopify-магазинів, AliExpress, Amazon, Facebook Ads Library, Google Shopping тощо. Результати — структуровані дані для прийняття рішень.

## Тригери

- "spy на конкурентів"
- "Apify"
- "зберіть дані з сайту"
- "проаналізуй конкурентів"
- "парсинг магазину"
- "знайди топ товари конкурентів"
- "Facebook Ads spy"

## Вхідні дані

- URL цільового сайту або назва платформи (Amazon, AliExpress, Shopify store)
- Мета дослідження: ціни / товари / оголошення / відгуки / ключові слова
- Параметри фільтрації: категорія, ціновий діапазон, кількість записів
- Формат виходу: Google Sheets / JSON / CSV

## Алгоритм

1. **Визначити ціль** — який сайт/платформа, яка інформація потрібна.
2. **Підібрати актор Apify** — вибрати з готових акторів або запропонувати кастомний підхід.
3. **Налаштувати вхідні параметри актора** — URL, ліміти, фільтри, проксі-налаштування.
4. **Запустити збір даних** — вказати як запустити (через Apify Console / API / Make.com інтеграцію).
5. **Обробити результати** — очистити, дедуплікувати, відсортувати за пріоритетом.
6. **Аналіз** — виявити патерни: топ товари, цінові діапазони, популярні категорії, активні оголошення.
7. **Звіт** — структурований висновок з рекомендаціями.

## Популярні Apify-актори

| Актор | Платформа | Що збирає |
|-------|-----------|-----------|
| `apify/shopify-scraper` | Shopify | Товари, ціни, колекції |
| `apify/amazon-product-scraper` | Amazon | Ціни, рейтинги, відгуки |
| `apify/aliexpress-scraper` | AliExpress | Товари, ціни, продажі |
| `apify/facebook-ads-scraper` | Facebook Ads Library | Активні оголошення |
| `apify/google-shopping-scraper` | Google Shopping | Ціни, магазини |
| `apify/instagram-scraper` | Instagram | Пости, хештеги, профілі |
| `apify/tiktok-scraper` | TikTok | Відео, тренди, хештеги |
| `apify/web-scraper` | Будь-який сайт | Кастомний парсинг |

## Правила

- Парсити тільки публічно доступні дані; не обходити авторизацію чи CAPTCHA на заборонених ресурсах.
- Використовувати Residential Proxy для сайтів з антибот-захистом (Amazon, AliExpress).
- Обмежувати кількість запитів (`maxItems`) щоб не перевищити Apify бюджет.
- Для регулярного моніторингу — налаштувати Schedule в Apify + вивантаження в Google Sheets.
- Дані конкурентів — для аналізу та натхнення, не для прямого копіювання контенту.
- Зберігати результати з датою збору (колонка `scraped_at`) для трекінгу змін.
