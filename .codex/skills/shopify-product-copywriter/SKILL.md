# Skill: shopify-product-copywriter

## Що робить

Пише продаючі тексти для карток товарів у Shopify: назву, опис, маркований список переваг, SEO-метадані. Враховує цільову аудиторію, ключові слова і психологію продажів. Не копіює AliExpress — пише оригінально.

## Тригери

- "напиши опис товару"
- "product copy"
- "текст для картки товару"
- "перепиши опис"
- "зроби SEO-опис"
- "bullet points для товару"

## Вхідні дані

- Назва або URL товару (обов'язково)
- Цільова аудиторія (хто купує?)
- Ключова вигода або проблема, яку вирішує товар
- Тон бренду (якщо є: дружній / експертний / веселий)
- Ринок: мова і країна
- Ключові слова для SEO (якщо є)

## Алгоритм (кроки)

### Крок 1 — Аналіз товару
Перед написанням визнач:
- Головна вигода (benefit), не характеристика (feature)
- Проблема покупця, яку вирішує товар
- Заперечення, які потрібно закрити в тексті
- Унікальна відмінність від конкурентів

Формула: "Хто хоче [результат], використовуючи [товар], щоб [вигода]"

### Крок 2 — Заголовок (Title)
Структура: [Прикметник-вигода] + [Тип товару] + [Ключова хар-ка або аудиторія]

Приклади:
- ❌ "2024 New Portable Mini Fan USB Cooling" (AliExpress-стиль)
- ✅ "Compact USB Desk Fan — Silent Cooling for Home Office"
- ✅ "Orthopedic Pet Bed — Memory Foam for Dogs & Cats"

Довжина: 50–70 символів. Без CAPS, без "!!!", без зайвих слів.

### Крок 3 — Опис товару (Body)
Структура опису (300–500 слів):

**1. Гачок (1–2 речення)**
Звернення до болю або бажання аудиторії. Питання або твердження, що одразу чіпляє.

**2. Основний опис (2–3 абзаци)**
- Що робить товар і як
- Для кого призначений
- Який результат отримує покупець
Писати від другої особи: "ти", "ваш", "ви отримаєте"

**3. Bullet points — переваги (5–7 пунктів)**
Формат кожного пункту:
`[Іконка або емодзі] [Назва переваги] — [розшифровка 1 реченням]`

Приклад:
- ✅ Тихий мотор (35 дБ) — не заважає дзвінкам і роботі
- ✅ USB-живлення — підключай до ноутбука, павербанку, адаптера

**4. Технічні характеристики**
Таблиця або список: матеріал, розмір, вага, колір, комплектація.

**5. CTA (заклик до дії)**
Останній абзац: "Замовляй сьогодні і [вигода від швидкого замовлення]"

### Крок 4 — SEO-метадані
**Meta Title (50–60 символів):**
`[Ключове слово] | [Назва магазину або USP]`

**Meta Description (120–155 символів):**
`[Ключова вигода] + [соціальний доказ або унікальність] + [CTA]`

**URL Handle:**
Лише латиниця, дефіси. Приклад: `usb-desk-fan-silent-office`

**Alt text для головного фото:**
`[Ключове слово] — [опис фото]`

### Крок 5 — Адаптація під ринок
- **США/Канада:** розмовний стиль, акцент на convenience і value
- **Великобританія:** трохи формальніше, акцент на quality
- **Україна/Польща:** опис детальніший, акцент на практичність і ціну
- **Загальне правило:** уникай слова "cheap" — використовуй "affordable" або "great value"

## Формат виводу

```
TITLE:
[готовий заголовок]

DESCRIPTION:
[готовий HTML-опис або markdown]

BULLET POINTS:
• [пункт 1]
• [пункт 2]
...

SEO META TITLE:
[текст]

SEO META DESCRIPTION:
[текст]

URL HANDLE:
[slug]
```

## Правила

- Ніколи не копіюй текст з AliExpress, навіть частково.
- Не використовуй "high quality", "best seller", "hot sale" — це сигнали дропшипінгу.
- Завжди пишеш з точки зору покупця (benefit-first), не продавця (feature-first).
- Перед фіналом — пропонуй запустити `shopify-product-preflight` для перевірки.
- Якщо немає ключових слів — генеруй самостійно на основі назви і ніші.
- Для кожного ринку перевіряй: чи використовуються правильні одиниці (дюйми/сантиметри, фунти/кілограми).
