# Google Sheets Automation

## Що робить цей скіл

Допомагає автоматизувати роботу з Google Sheets: будує складні формули, пише Apps Script, налаштовує тригери, створює інтеграції з Make.com, Zapier, Notion та іншими сервісами.

## Тригери (коли активується)

- "автоматизуй таблицю", "Google Sheets скрипт"
- "формула для", "як порахувати в Sheets"
- "зроби автоматичне оновлення", "підключи Sheets до..."
- "потрібен тригер у таблиці", "Apps Script для"

## Вхідні дані (що уточнити перед роботою)

1. **Мета**: що саме потрібно автоматизувати або порахувати?
2. **Структура таблиці**: назви аркушів, колонки, діапазони даних.
3. **Тип рішення**: формула / Apps Script / інтеграція / все разом?
4. **Тригер**: вручну, за розкладом, при зміні даних, через webhook?
5. **Доступи**: чи є редактор/власник таблиці (для скриптів)?

## Алгоритм роботи

### Крок 1 — Аналіз задачі
- Визначити: чи достатньо формули, чи потрібен скрипт.
- Формули — для обчислень та фільтрації в реальному часі.
- Apps Script — для складних дій: надсилання email, запису в БД, API-запитів.

### Крок 2 — Формули (якщо достатньо)
Вибрати оптимальний підхід:
- `QUERY` — для SQL-подібної фільтрації та агрегації.
- `ARRAYFORMULA` — масові обчислення без копіювання формули вниз.
- `IMPORTRANGE` — підтягування даних з іншої таблиці.
- `VLOOKUP` / `XLOOKUP` — пошук і підстановка значень.
- `REGEXEXTRACT` / `REGEXMATCH` — робота з текстом за патерном.

### Крок 3 — Apps Script (якщо потрібна логіка)
Структура скрипту:
```javascript
function myFunction() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  const sheet = ss.getSheetByName("Назва аркуша");
  const data = sheet.getDataRange().getValues();
  // логіка обробки
}
```
Додати тригер: Розширення → Apps Script → Тригери → Новий тригер.

### Крок 4 — Інтеграція з Make/Zapier
- Make: модуль "Google Sheets → Watch Rows" або "Update Row".
- Zapier: тригер "New Spreadsheet Row", дія "Update Spreadsheet Row".
- Webhook: через Apps Script `doPost(e)` отримати дані від Make.

### Крок 5 — Тестування
- Запустити скрипт вручну, перевірити лог (Вигляд → Журнал виконання).
- Перевірити формулу на тестових даних.
- Для тригерів — симулювати подію.

## Формат відповіді

- Готова формула або скрипт у блоці коду.
- Покрокова інструкція встановлення.
- Пояснення логіки — коротко, зрозуміло.
- Попередження про можливі ліміти (квоти Apps Script, ліміт IMPORTRANGE).

## Правила

- Не використовувати `SpreadsheetApp.flush()` без потреби — сповільнює.
- Масиви читати/писати за один виклик (не по одній клітинці в циклі).
- Для великих таблиць (>10k рядків) пропонувати QUERY замість FILTER.
- Зберігати чутливі дані (API ключі) у Properties Service, не в коді.
- Вказувати часовий пояс при роботі з датами у тригерах.
