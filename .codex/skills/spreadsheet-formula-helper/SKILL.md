# Spreadsheet Formula Helper

## Що робить цей скіл

Пише складні та прості формули для Google Sheets і Excel: пошук, агрегація, умовна логіка, масиви, регулярні вирази, динамічні діапазони. Пояснює кожен аргумент і пропонує альтернативи.

## Тригери (коли активується)

- "напиши формулу", "формула Excel", "формула Sheets"
- "як порахувати в таблиці", "як знайти значення"
- "VLOOKUP не працює", "зроби SUMIF", "потрібен QUERY"
- "як витягнути текст", "умовне форматування формулою"
- "формула з кількома умовами", "підрахувати унікальні значення"

## Вхідні дані (що уточнити перед роботою)

1. **Платформа**: Google Sheets чи Excel? (синтаксис відрізняється!)
2. **Задача**: що потрібно обчислити або знайти?
3. **Структура даних**: які стовпці, з яких рядків починаються дані?
4. **Критерії**: умови фільтрації, діапазони значень?
5. **Формат результату**: число, текст, дата, список?

## Алгоритм роботи

### Крок 1 — Визначити категорію задачі
- **Пошук і підстановка** → VLOOKUP / XLOOKUP / INDEX+MATCH
- **Агрегація з умовою** → SUMIF / COUNTIF / AVERAGEIF / SUMIFS
- **Масиви і фільтрація** → ARRAYFORMULA / FILTER / QUERY (Sheets)
- **Текст** → LEFT / MID / RIGHT / REGEXEXTRACT / SUBSTITUTE / TEXTJOIN
- **Дати** → DATEDIF / EDATE / NETWORKDAYS / TEXT / EOMONTH
- **Логіка** → IF / IFS / SWITCH / AND / OR / NOT

### Крок 2 — Побудувати формулу

**Пошук значення (Sheets і Excel):**
```
=XLOOKUP(A2, Таблиця!A:A, Таблиця!C:C, "Не знайдено")
=INDEX(C:C, MATCH(A2, A:A, 0))
```

**Сума за умовою (Sheets і Excel):**
```
=SUMIFS(D:D, B:B, "Активний", C:C, ">="&DATE(2024,1,1))
```

**Масовий розрахунок без копіювання (тільки Sheets):**
```
=ARRAYFORMULA(IF(A2:A<>"", B2:B * C2:C, ""))
```

**SQL-фільтрація (тільки Sheets):**
```
=QUERY(A1:E100, "SELECT A, B, SUM(D) WHERE C='Активний' GROUP BY A, B LABEL SUM(D) 'Сума'", 1)
```

**Витягнути текст за патерном (Sheets):**
```
=REGEXEXTRACT(A2, "\d{10}")
=REGEXREPLACE(A2, "[^0-9]", "")
```

**Витягнути текст (Excel):**
```
=MID(A2, FIND("@", A2)+1, LEN(A2))
```

**Унікальні значення і підрахунок:**
```
=COUNTIF(A:A, A2)                    -- скільки разів зустрічається
=SUMPRODUCT(1/COUNTIF(A2:A100,A2:A100))  -- кількість унікальних
```

**Динамічний діапазон (Sheets):**
```
=COUNTA(A:A)-1                       -- кількість рядків з даними
=INDIRECT("A2:A"&COUNTA(A:A))        -- діапазон до останнього рядка
```

### Крок 3 — Перевірити і пояснити

Розкласти формулу на частини:
```
=SUMIFS(
  D2:D100,    -- стовпець значень для підсумовування
  B2:B100,    -- стовпець першої умови
  "Активний", -- перша умова
  C2:C100,    -- стовпець другої умови
  ">100"      -- друга умова
)
```

### Крок 4 — Запропонувати альтернативи
- Якщо VLOOKUP — запропонувати XLOOKUP (новіший, гнучкіший).
- Якщо ARRAYFORMULA — перевірити чи підходить BYROW/BYCOL (Sheets 2023+).
- Якщо QUERY — перевірити чи потрібен FILTER (простіший синтаксис).

## Формат відповіді

- Готова формула у блоці коду.
- Розбивка аргументів з поясненням.
- Де вставити формулу (комірка, діапазон).
- Можливі помилки та як їх уникнути (#N/A, #REF!, #VALUE!).

## Правила

- Завжди уточнювати платформу: деякі функції є тільки в Sheets (QUERY, REGEXEXTRACT, IMPORTRANGE) або тільки в Excel (XLOOKUP в старих версіях, UNIQUE в нових).
- Роздільник аргументів: кома `,` (Sheets/EN Excel) або крапка з комою `;` (Excel UA/RU локаль).
- ARRAYFORMULA в Sheets не потребує Ctrl+Shift+Enter на відміну від формул масиву в Excel.
- Для великих діапазонів (>100k рядків) попереджати про уповільнення ARRAYFORMULA; рекомендувати QUERY або скрипт.
- Не використовувати цілі стовпці (A:A) у ARRAYFORMULA — це може спричинити зависання.
- Для умовного форматування — надавати формулу окремо від формули комірки.
