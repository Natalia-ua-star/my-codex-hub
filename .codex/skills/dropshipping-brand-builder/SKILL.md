# Skill: dropshipping-brand-builder

## Що робить

Будує бренд-ідентичність для дропшипінг-магазину з нуля: генерує варіанти назви, формулює USP, визначає tone of voice, готує бриф для логотипу та кольорову палітру. Результат — готовий бренд-документ для налаштування магазину і реклами.

## Тригери

- "придумай назву для магазину"
- "створи бренд"
- "brand identity"
- "бренд для магазину"
- "як назвати магазин"
- "tone of voice"
- "USP магазину"

## Вхідні дані

Запитай у користувача:
1. Ніша / категорія товарів
2. Цільова аудиторія (вік, стать, інтереси)
3. Цільовий ринок (країна)
4. Товар-герой або головна ідея магазину
5. Стиль, що подобається (мінімалізм / яскравий / натуральний / технологічний)

## Алгоритм (кроки)

### Крок 1 — Аналіз ніші та аудиторії
- Визнач головний біль або бажання цільової аудиторії
- Сформулюй 1 реченням: "Ми допомагаємо [аудиторія] досягти [результат] за допомогою [продукт]"
- Перевір конкурентів: як вони себе позиціонують? Де є незайнята ніша?

### Крок 2 — Назва магазину
Згенеруй 5–7 варіантів назви в різних стилях:
- **Описова:** відображає що продаєш (NestComfort, PetEssentials)
- **Емоційна:** викликає відчуття (Lumina, Cozyly)
- **Вигадана:** унікальне слово (Zevio, Flayne)
- **Скорочення або злиття:** (PetGo, HomiX)

Критерії хорошої назви:
- 1–2 склади або максимум 3 слова
- Легко вимовляється англійською (якщо ринок США/ЄС)
- Домен .com доступний (перевір через namecheap або godaddy)
- Не зареєстрована як торгова марка в основній категорії

### Крок 3 — USP (Унікальна торгова пропозиція)
Сформулюй 2–3 варіанти USP у форматі:
"[Що робимо] + [для кого] + [унікальна відмінність]"

Приклади хорошого USP:
- "Товари для організації дому, яких немає в IKEA"
- "Аксесуари для домашніх тварин, які обирають ветеринари"
- "Гаджети для авто — доставка за 7 днів або повернення грошей"

### Крок 4 — Tone of Voice
Визнач стиль комунікації бренду (обери 2–3 з пар):
- Дружній / Офіційний
- Веселий / Серйозний
- Надихаючий / Практичний
- Простий / Експертний

Дай 3 приклади фраз у визначеному ToV:
- Для опису товару
- Для Instagram підпису
- Для email-заголовку

### Крок 5 — Візуальна ідентичність (бриф)
**Кольорова палітра:**
- Основний колір (hex) + значення
- Додатковий колір + акцентний
- Рекомендація: не більше 3 кольорів

**Логотип-бриф для дизайнера / Canva:**
- Стиль: мінімалістичний / ілюстративний / типографічний
- Настрій: тепло / холодно / нейтрально
- Що обов'язково включити / виключити
- Референси: 2–3 бренди зі схожим стилем

**Шрифти (рекомендація):**
- Заголовок: + назва Google Font
- Тіло тексту: + назва Google Font

### Крок 6 — Бренд-документ
Зведи все в короткий документ:

```
БРЕНД: [назва]
USP: [одне речення]
АУДИТОРІЯ: [опис]
TON OF VOICE: [3 слова]
КОЛЬОРИ: [hex-коди]
ШРИФТИ: [назви]
ДОМЕН: [перевірити]
```

## Формат виводу

- Блок 1: Топ-3 рекомендовані назви з поясненням + всі 5–7 варіантів
- Блок 2: Кращий USP + 2 альтернативи
- Блок 3: Tone of Voice з прикладами
- Блок 4: Бриф на логотип і палітра
- Блок 5: Готовий бренд-документ (копіювати в Notion/Google Doc)

## Правила

- Не пропонуй назви, що звучать схоже на великі бренди (юридичний ризик).
- Перевіряй назви на звучання і написання — уникай двозначностей.
- Завжди пропонуй варіанти домену: .com пріоритет, потім .co, .shop, .store.
- Якщо ринок США — назва має легко вимовлятись для американця.
- Після затвердження назви — передай в `shopify-store-setup` для реєстрації домену.
